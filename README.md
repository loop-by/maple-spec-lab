# 메키 스펙 연구소

메이플 키우기 한국 서버용 **초기 연구 버전**입니다. 넥슨 공식 일반 피해식을 바탕으로 현재 스펙과 옵션 교체를 비교합니다. 실제 게임의 모든 직업·콘텐츠에서 오차가 검증된 완성형 시뮬레이터는 아닙니다.

## 실행

Node.js 22 이상. 설치할 외부 패키지가 없습니다.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
```

`dist/` 전체가 정적 사이트입니다. 서버, DB, 비밀키, 게임 계정 연동이 없습니다. 파일을 직접 더블클릭하면 ES 모듈이 차단될 수 있으므로 HTTP 서버로 실행하세요.

## 구현한 기능

- 29개 스펙 필드, 보스/일반·기본/스킬·일반/제곱근/세제곱근 콘텐츠 비교
- 브라우저 자동 저장, 최대 20개 프리셋, JSON 백업·추가 불러오기
- 부위별 미라클·에디셔널 3줄, 어빌리티 3줄 비교안, 부위 추가
- 현재 합계에서 기존 출처를 제거한 뒤 목표 출처를 적용하는 옵션 교체
- 각 줄과 전체 교체의 평균 1회 피해 증가율
- 사용자가 입력한 목표 후보·전체 성공 확률·동일 단위 비용에 한정한 효율 순위
- 고정 확률 기댓값, 실제 목표를 보장하는 hard pity, 중앙값·90%·95% 달성 횟수
- 독립 줄 가정의 Poisson-binomial 계산, 조건부 등급·종류·이산 균등 수치의 어빌리티 목표 확률
- 측정 당시 스펙·모델 버전이 포함된 실측 기록, 오차·공통 배율 역산, CSV 다운로드

## 정확도와 미완료 사항

**공식과 구현의 수학적 일치**와 **실제 게임 실측 일치**를 구분합니다. `npm test`는 전자를 검증합니다. 실측 자료는 아직 제공받지 않았으며 후자를 주장하지 않습니다.

기본식·출처 누적 방식·콘텐츠 거듭제곱은 [넥슨 공식 추가 정보](https://maplestoryidle.nexon.com/ko/guide)의 2026.10.15 버전을 2026.10.24에 직접 확인했습니다. 참고 자료와 검증 계획은 [RESEARCH.md](docs/RESEARCH.md)에 있습니다.

현재 공식 전체 확률표는 앱에 탑재되지 않았습니다. 목표 조합의 1회 성공 확률을 직접 입력하는 계산기로, 등급업과 옵션 등장 확률을 혼동하지 않아야 합니다. 상태에 따라 확률이 달라지는 승급·변환 레벨·잠금·천장 복합 과정은 지원하지 않습니다.

주스탯/공격력 % 원시 환산은 미확정입니다. 현재 표시 공격력과 스탯 비례 데미지를 직접 입력합니다. 해당 % 옵션을 바꾸려면 현재 스펙 주변에서 실측한 두 환산 기울기를 넣어야 하며 결과는 선형 추정입니다. 공속·쿨감은 기록만 합니다. 전체 전투 DPM, 스킬 로테이션, 동료·유물 발동, PVP는 구현 범위 밖입니다.

콘텐츠 상수 기본값 1은 상대 비교용이며 실제 레이드 절대 피해를 뜻하지 않습니다. 치명타 배율 입력은 **총 배율**로, 추가 피해 30%는 130을 넣습니다. 랜덤 배율은 연속 균등 분포로 가정하며, 클라이언트의 이산 추첨·반올림 순서는 실측 확인이 필요합니다.

## 저비용 운영

권장 구조는 **정적 웹 + 브라우저 계산 + localStorage + JSON 백업**입니다. 각 사용자는 자신의 브라우저에 독립 데이터를 갖습니다. 여러 명이 같은 주소로 사용할 수 있지만 기기 간 자동 동기화는 없습니다.

[Cloudflare Pages 공식 요금](https://developers.cloudflare.com/pages/functions/pricing/)상 Functions를 호출하지 않는 정적 파일 요청은 무료입니다(2026.10.24 확인). 무료 기본 도메인과 현재 구조를 사용하면 인프라 비용 $0부터 가능합니다. [무료 빌드·파일 한도](https://developers.cloudflare.com/pages/platform/limits/)는 별도 적용됩니다. Sites 미리보기의 요금이 Cloudflare 무료 상품과 동일하다는 뜻은 아닙니다.

Google Sheets는 공식 역산·실측 데이터 검산과 공용 확률표 관리에 적합합니다. 개인별 사본과 웹 UI·스크립트를 관리해야 하므로 이 서비스의 주 인터페이스로는 정적 웹이 더 단순합니다. 추후 확률 테이블을 Sheets에서 편집하고 배포 시 JSON으로 내보내는 구성을 사용할 수 있습니다. 사용자 캐릭터 데이터를 공개 시트에 저장하지 않습니다.

자동 동기화가 필요해질 때 로그인과 저장 API를 추가하고 비용을 다시 산정하세요. OCR/LLM 호출은 이 버전에 포함하지 않아 사용량 과금이 발생하지 않습니다.

## 구성

- `dist/engine.mjs`: DOM 없는 순수 계산 엔진
- `dist/app.mjs`: 입력·프리셋·비교·확률·실측 UI
- `test/engine.test.mjs`: 독립적인 기대값과 비교하는 수학 검산
- `docs/RESEARCH.md`: 출처, 수식 정의, 미확정 항목, 실측 계획
- `.openai/hosting.json`: 비공개 Sites 미리보기 식별 정보

비공식 팬 프로젝트로 NEXON 및 Able Games와 무관합니다.
