# 메키 스펙 연구소

MapleStory: Idle RPG / 메이플 키우기용 **초기 연구 버전**입니다. 기본 환경은 사용자가 확인한 **Global / PC 1.17.0**이며 한국 지역도 선택할 수 있습니다. 넥슨 공식 일반 피해식을 바탕으로 현재 스펙과 옵션 교체를 비교합니다. 실제 게임의 모든 직업·콘텐츠에서 오차가 검증된 완성형 시뮬레이터는 아닙니다.

## 실행

Node.js 22 이상. npm 패키지 설치나 API 키 설정 없이 실행합니다. 사진 인식에 필요한 라이브러리·한국어/영어 모델은 `dist/vendor/ocr/`에 포함되어 있습니다.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
```

`dist/` 전체가 정적 사이트입니다. 서버, DB, 비밀키, 게임 계정 연동이 없습니다. 파일을 직접 더블클릭하면 ES 모듈이 차단될 수 있으므로 HTTP 서버로 실행하세요.

## 스크린샷으로 스탯 가져오기

1. 게임의 **상세 스탯 창**에서 항목명과 현재 합계가 보이도록 캡처합니다.
2. **내 스펙 → 스탯 사진 가져오기**에서 사진을 선택합니다. 모바일 앨범에서 여러 장을 선택할 수 있고, PC에서는 이미지를 붙여넣을 수도 있습니다.
3. 빠진 스탯은 **사진 추가**로 보충할 수 있습니다. 앞서 수정한 숫자·표기 방식·제외한 항목은 유지하고 추가한 사진만 읽습니다.
4. 사진과 읽힌 값을 비교합니다. 불확실한 값·사진마다 다른 값은 기본적으로 선택하지 않습니다. 필요하면 값을 고친 뒤 반영할 항목을 선택하세요.
5. **스탯 반영**을 누르면 선택한 값만 기존 프리셋에 반영됩니다. 다른 편집을 하기 전까지 **이번 반영 되돌리기**로 취소할 수 있습니다.

- PNG/JPG/WebP 최대 6장, 한 장당 15MB·전체 50MB. HEIC는 PNG/JPG로 변환해야 합니다.
- 한국어/영어 항목명, 쉼표·소수점·퍼센트, `억·만·조·천`, `K/M/B/T` 표기를 지원합니다. 지원하지 않거나 잘못 읽힌 항목은 자동 추측하지 않습니다.
- 크리티컬 데미지 표기가 모호하면 총 배율인지 추가 피해인지 선택합니다. 예: 추가 피해 50% → 총 배율 150%.
- 사진에 없는 항목은 기존 입력값을 유지합니다. 처음 사용 중인 예제 프리셋에는 예제 값이 남을 수 있으며, 일부 항목을 가져왔다고 전체 스탯을 검증한 것은 아닙니다.
- 새 사진을 반영하면 기존 버프 비교 기준을 해제합니다. 이후 버프 변경을 비교하려면 촬영 당시 버프 상태를 다시 지정하세요.
- 사진은 브라우저의 Web Worker에서 처리하고 서버에 전송하지 않습니다. 원본·인식 텍스트·이미지 조각은 저장하지 않고 창을 닫을 때 해제합니다. 확인한 숫자만 기존 프리셋에 저장합니다.
- 처음 사용할 때 같은 사이트에서 인식 엔진·언어 모델을 불러오므로 시간이 걸릴 수 있습니다. 진행 중 취소할 수 있습니다. 서버측 AI 호출이나 사용량 과금은 없습니다.

일반적인 스탯 목록을 대상으로 구현했으며 실제 게임 캡처의 모든 해상도·UI·글꼴에서 정확도를 검증하지는 않았습니다. 장비 옵션·스킬 설명·버프 목록을 자동 등록하는 기능은 포함하지 않습니다. 실제 기기 캡처로 항목명과 인식률을 확인해야 합니다.

인식 파일의 출처·라이선스·재생성 방법은 [OCR 파일 안내](dist/vendor/ocr/README.md)를 참고하세요.

배포할 때는 `dist/` 전체를 포함해야 합니다. Python 3으로 OCR 파일의 무결성을 확인하고 정적 사이트 ZIP을 만들 수 있습니다.

```sh
python3 scripts/package-site.py /tmp/maple-spec-lab-site.zip
```

ZIP 최상위에 `index.html`이 있고, 모든 정적 파일과 `SHA256SUMS`가 포함됩니다. ZIP 생성은 공개 사이트 배포를 실행하지 않습니다. 기존 ChatGPT Sites 프로젝트는 `.openai/hosting.json`에 지정되어 있습니다.

### GitHub Pages 배포

이 프로젝트는 GitHub Pages에서도 `dist/` 전체를 정적 사이트로 배포할 수 있습니다. `.github/workflows/pages.yml`이 테스트와 OCR 파일 무결성 확인을 통과한 뒤 배포합니다.

1. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
2. 스크린샷 기능과 배포 설정이 포함된 `work` 브랜치를 `main`에 병합합니다.
3. **Actions → Deploy to GitHub Pages** 실행이 완료되면 배포 작업의 `github-pages` 환경 링크에서 사이트를 엽니다. 필요하면 `main`을 선택해 **Run workflow**로 다시 배포할 수 있습니다.

기본 프로젝트 주소는 `https://loop-by.github.io/maple-spec-lab/`입니다. 커스텀 도메인을 설정하면 주소가 달라질 수 있습니다. `main`에 새 커밋을 push하면 자동으로 다시 배포하며, PR에서는 테스트와 파일 확인만 실행합니다. 정적 파일과 OCR 자료는 프로젝트 하위 경로를 기준으로 불러옵니다.

GitHub Pages의 주소는 기존 ChatGPT Sites 주소와 다릅니다. 브라우저 저장 데이터는 주소별로 분리되므로 기존 사이트에서 JSON으로 백업한 뒤 새 주소에서 불러오세요. 저장소가 비공개이면 GitHub 요금제에서 Pages를 지원하는지 확인해야 하며, 이 설정은 저장소 공개 범위를 변경하지 않습니다.

## 구현한 기능

- 29개 스펙 필드, 보스/일반·기본/스킬·일반/제곱근/세제곱근 콘텐츠 비교
- 브라우저 자동 저장, 최대 20개 프리셋, JSON 백업·추가 불러오기
- 부위별 미라클·에디셔널 3줄, 어빌리티 3줄 비교안, 부위 추가
- 현재 합계에서 기존 출처를 제거한 뒤 목표 출처를 적용하는 옵션 교체
- 각 줄과 전체 교체의 평균 1회 피해 증가율
- 사용자가 입력한 목표 후보·전체 성공 확률·동일 단위 비용에 한정한 효율 순위
- 고정 확률 기댓값, 실제 목표를 보장하는 hard pity, 중앙값·90%·95% 달성 횟수
- 독립 줄 가정의 Poisson-binomial 계산, 조건부 등급·종류·이산 균등 수치의 어빌리티 목표 확률
- 측정 당시 스펙·모델 버전이 포함된 실측 기록, 오차·공통 배율 역산, CSV 다운로드

## 직업·스킬·버프 (v0.2)

- 14직업을 한국어/영문 이름으로 선택하고 캐릭터 레벨·실제 완료한 전직을 기록
- 기본 스킬 434개·마스터리 812개의 수치 사실·해금·연구 정보 조회
- 레벨·전직 기준 습득 설정, 실제 습득/스킬 레벨 수정, 버프·패시브 토글
- 36개 공통 효과 카드: 길드·캐시·기간제 의상·유물·훈장·소모품 등 일부
- 현재 스탯에 포함된 효과를 기준으로 저장한 뒤, 바뀐 출처만 제거·적용하여 중복 계산 방지
- 미확정 수치는 직접 실측 스탯 변화량으로 보정. 프리셋·백업에 버프 상태도 저장
- Global 미확인 수치와 콘텐츠 전용 효과에 적용 제한

**상세 스킬 표는 1.15.0 보조 자료입니다. 현재 PC 1.17.0의 전체 최신 수치를 검증한 표가 아닙니다.** 마스터리 효과 자동 합성, 길드 전체 레벨별 표, 모든 상품·보유 효과의 전수 자료는 남아 있습니다. [자료 범위·버전·사용법](docs/CATALOG.md)을 확인하세요.

## 정확도와 미완료 사항

**공식과 구현의 수학적 일치**와 **실제 게임 실측 일치**를 구분합니다. `npm test`는 전자를 검증합니다. 실측 자료는 아직 제공받지 않았으며 후자를 주장하지 않습니다.

기본식·출처 누적 방식·콘텐츠 거듭제곱은 [넥슨 공식 추가 정보](https://maplestoryidle.nexon.com/ko/guide)의 2026.10.15 버전을 2026.10.24에 직접 확인했습니다. 참고 자료와 검증 계획은 [RESEARCH.md](docs/RESEARCH.md)에 있습니다.

현재 공식 전체 확률표는 앱에 탑재되지 않았습니다. 목표 조합의 1회 성공 확률을 직접 입력하는 계산기로, 등급업과 옵션 등장 확률을 혼동하지 않아야 합니다. 상태에 따라 확률이 달라지는 승급·변환 레벨·잠금·천장 복합 과정은 지원하지 않습니다.

주스탯/공격력 % 원시 환산은 미확정입니다. 현재 표시 공격력과 스탯 비례 데미지를 직접 입력합니다. 해당 % 옵션을 바꾸려면 현재 스펙 주변에서 실측한 두 환산 기울기를 넣어야 하며 결과는 선형 추정입니다. 공속·쿨감은 기록만 합니다. 전체 전투 DPM, 스킬 로테이션, 동료·유물 발동, PVP는 구현 범위 밖입니다.

콘텐츠 상수 기본값 1은 상대 비교용이며 실제 레이드 절대 피해를 뜻하지 않습니다. 치명타 배율 입력은 **총 배율**로, 추가 피해 30%는 130을 넣습니다. 랜덤 배율은 연속 균등 분포로 가정하며, 클라이언트의 이산 추첨·반올림 순서는 실측 확인이 필요합니다.

## 저비용 운영

권장 구조는 **정적 웹 + 브라우저 계산 + localStorage + JSON 백업**입니다. 각 사용자는 자신의 브라우저에 독립 데이터를 갖습니다. 여러 명이 같은 주소로 사용할 수 있지만 기기 간 자동 동기화는 없습니다.

[Cloudflare Pages 공식 요금](https://developers.cloudflare.com/pages/functions/pricing/)상 Functions를 호출하지 않는 정적 파일 요청은 무료입니다(2026.10.24 확인). 무료 기본 도메인과 현재 구조를 사용하면 인프라 비용 $0부터 가능합니다. [무료 빌드·파일 한도](https://developers.cloudflare.com/pages/platform/limits/)는 별도 적용됩니다. Sites 미리보기의 요금이 Cloudflare 무료 상품과 동일하다는 뜻은 아닙니다.

Google Sheets는 공식 역산·실측 데이터 검산과 공용 확률표 관리에 적합합니다. 개인별 사본과 웹 UI·스크립트를 관리해야 하므로 이 서비스의 주 인터페이스로는 정적 웹이 더 단순합니다. 추후 확률 테이블을 Sheets에서 편집하고 배포 시 JSON으로 내보내는 구성을 사용할 수 있습니다. 사용자 캐릭터 데이터를 공개 시트에 저장하지 않습니다.

자동 동기화가 필요해질 때 로그인과 저장 API를 추가하고 비용을 다시 산정하세요. OCR은 브라우저 안에서 실행하며 외부 AI API를 호출하지 않아 API 사용량 과금이 발생하지 않습니다.

## 구성

- `dist/engine.mjs`: DOM 없는 순수 계산 엔진
- `dist/app.mjs`: 입력·프리셋·비교·확률·실측 UI
- `dist/catalog*.mjs`, `dist/buff-*.mjs`, `dist/buffs.css`: 직업·버프 자료, 기준 대비 적용 엔진과 UI
- `docs/CATALOG.md`: Global/PC 버전 검증, 수치 자료 범위, 출처와 제한
- `test/engine.test.mjs`: 독립적인 기대값과 비교하는 수학 검산
- `docs/RESEARCH.md`: 출처, 수식 정의, 미확정 항목, 실측 계획
- `.openai/hosting.json`: 공개 ChatGPT Sites 프로젝트 식별 정보
