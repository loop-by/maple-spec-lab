# 직업·버프 자료와 Global 버전 구분

조사 시각: 2026-10-25 UTC (미국 동부 10월24일). 사용자가 시작 화면에서 확인한 환경은 **Global / PC 1.17.0**입니다.

## 앱 버전과 표 버전

- 미국과 한국 iOS App Store는 같은 앱 ID `6739616715`, 같은 버전 `1.17.1`과 업데이트 이력을 표시합니다. 이는 같은 앱 배포라는 근거이며, 모든 서버 설정·상품 문구까지 같다는 증명은 아닙니다.
- 사용자의 PC 표시 버전은 `1.17.0`입니다. iOS의 패치 번호가 다르다는 이유만으로 PC의 밸런스가 뒤처졌다고 결론 내리지 않습니다. PC 실행 방식·배포 채널은 추가 확인 전입니다.
- 확보한 상세 직업 수치 표는 **클라이언트 1.15.0** 보조 자료입니다. 현재 1.17.0의 전수 검증 표로 표시하지 않습니다.
- Global 8/13 공식 밸런스 변경의 일부 수치와 보조 표가 일치합니다. Global·KR 10/15의 주요 콘텐츠 추가도 같습니다. 다만 핑크빈 길드 레이드의 입장 조건은 양쪽 공지의 문구가 달라, 지역별 조건을 일괄 동일하게 처리하지 않습니다. 실제 서버 차이인지 번역 차이인지는 미확정입니다.
- 기본 피해식은 Global 공식 영문 가이드와 기존 한국어 가이드를 대조했습니다. `MODEL_VERSION`은 수학 모델 식별자이고, 직업 자료 버전과 별개입니다.

## 기준 스탯과 토글

1. 현재 게임 스탯 창의 합계를 입력합니다.
2. 직업·레벨·실제 완료한 전직, 배운 스킬과 실제 스킬 레벨을 설정합니다. 캐릭터 레벨만으로 스킬 강화 포인트의 투자 결과를 추측하지 않습니다.
3. 스탯 창을 확인했을 때 켜져 있던 효과를 선택하고 **현재 선택을 입력 스탯의 기준으로 저장**합니다.
4. 이후 버프 토글·스킬 레벨을 바꾸면 기준 출처를 제거하고 현재 출처를 적용합니다. 변하지 않은 출처는 먼저 상쇄해 주스탯 환산 같은 불필요한 역산을 하지 않습니다.
5. 알 수 없는 출처가 실제로 바뀌면 계산을 멈추고 수치 확인을 요구합니다. 해당 효과의 전체 실측 스탯 변화량을 직접 입력할 수 있습니다. 같은 스킬 레벨의 미확인 기준 수치도 함께 보정됩니다.

기준을 설정하기 전에는 입력 스탯만 계산하고 ‘기준 미설정’을 표시합니다. 공격 속도·쿨다운·추가타·로테이션은 현재 정적 1회 피해에 자동 합산하지 않습니다. 버프의 지속시간이나 발동 주기를 평균 가동률로 추정하지도 않습니다.

KR에서만 확인한 공통 효과는 Global 자동 적용을 막습니다. 사용자가 직접 수치를 확인해 입력하면 사용할 수 있습니다. 챕터 방치 전용 부스터, 자쿰·혼테일 전용 유물은 선택한 콘텐츠 조건으로 제한합니다.

## 유지보수

`dist/catalog-data.mjs`는 배포되는 사실 데이터입니다. `dist/catalog.mjs`는 수치 곡선을 표시하고, `buff-engine.mjs`는 습득·적용 조건과 기준 대비 출처 교체를 계산합니다. `buff-view.mjs`와 `buffs.css`가 UI를 제공합니다.

검토된 사실 JSON을 다시 컴파일할 때만 다음 명령을 사용합니다. 내려받은 JavaScript 코드를 실행하지 않습니다.

```sh
python3 scripts/build-catalog.py --jobs /path/job-catalog.json --shared /path/shared-catalog.json
```

로컬 검산에는 기존 피해식 테스트와 출처 상쇄·최종뎀 제거·미확정 처리·해금·지역·콘텐츠 조건 검사가 포함됩니다. 이 검사는 현재 게임의 모든 스킬 수치가 정확하다는 실측 검증을 대신하지 않습니다.
